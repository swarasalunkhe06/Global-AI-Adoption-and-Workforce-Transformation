# 🌍 Global AI Adoption & Workforce Impact Analysis

## 📌 Project Overview

Artificial Intelligence is changing how businesses operate and how people work. This project uses **Microsoft Power BI** to explore global AI adoption patterns and examine business and workforce-related themes, including the changing demand for AI skills and reskilling.

The project presents the analysis through an interactive, multi-page dashboard designed to make data easier to explore and communicate.

## 🎯 Problem Statement

As AI adoption continues to expand across industries, organisations and workers need to understand where AI is being adopted and how it may influence business activities and workforce skills. This project brings together relevant data to explore these themes and communicate patterns through interactive visualisations.

## 🎯 Project Objectives

- 🌍 Explore AI adoption patterns across countries, regions and industries.
- 🏢 Examine business-related aspects of AI adoption.
- 💼 Explore workforce and employment-related themes represented in the available data.
- 📚 Review AI reskilling and upskilling patterns.
- 📊 Present findings through clear, interactive Power BI dashboards.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning, transformation and preparation.
- **DAX** – Measures and analytical calculations.
- **Exploratory Data Analysis (EDA)** – Examining data patterns and trends.

## 📂 Dataset

The project uses the following publicly available datasets:

1. [Global AI Adoption and Workforce Impact Dataset – Kaggle](https://www.kaggle.com/datasets/mohankrishnathalla/global-ai-adoption-and-workforce-impact-dataset)

The skills and training data from the second source was used to support the reskilling and upskilling analysis.


## ⚙️ Methodology

1. **Data Loading:** Imported the selected datasets into Power BI.
2. **Data Preparation:** Used Power Query to review data types, missing values and data consistency.
3. **Data Modelling:** Organised the data for analysis and considered relationships between relevant tables.
4. **Calculations:** Used DAX for report measures and analytical calculations.
5. **Visualization:** Built interactive report pages to explore the main project themes.
6. **Analysis:** Reviewed visualised data to identify patterns and communicate observations.

## 📊 Dashboard Pages

The Power BI report contains five interactive pages:

| Page | Description |
|---|---|
| 🏠 **Overview** | Provides a high-level introduction to the project and its main indicators. |
| 🌍 **Adoption** | Explores AI adoption across available countries, regions and industries. |
| 🏢 **Business Impact** | Examines business and workforce-related aspects represented in the dataset. |
| 🎓 **Reskilling** | Explores AI-related skills, training, reskilling and upskilling patterns. |
| 💡 **Insights** | Brings together selected observations from the analysis. |

## 🔍 Key Areas of Analysis

- 🌍 Global AI adoption patterns.
- 🏭 AI adoption across industries and regions.
- 📈 Business impact of AI adoption.
- 💼 Workforce and employment-related trends.
- 🎓 AI skills, training and reskilling patterns.

> The report is descriptive and exploratory. Interpretations are based on the available datasets and should not be treated as proof that AI alone caused a particular employment or business outcome.

## 🚀 How to Explore the Project

1. Download the `.pbix` Power BI report file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Navigate through the five report pages.
4. Use the available slicers and filters to explore the visualisations.
5. Review the charts and insights presented in the report.
